# 킨더에듀(Kinder Edu) 게임 제작 표준 지침 (GAME CREATION RULES)

킨더에듀 플랫폼 내 모든 인터랙티브 유아 교육 놀이(게임)의 제작, 에셋 구성, 음향 및 인터랙션 표준 가이드라인입니다.

---

## 1. 비주얼 & 아트 디렉션 (Visual & Art Standard)

### 🎨 표준 화풍: 따뜻한 파스텔 수채화 동화책 스타일
* **감성 톤앤매너**:
  * 아이들의 정서적 안정과 집중을 돕는 **따뜻하고 차분한 파스텔 수채화 그림책 느낌**.
  * 자극적이거나 쨍한 원색(Neon)을 지양하고, 부드러운 수채화 번짐과 은은한 종이 질감이 느껴지는 자연스러운 색채를 사용합니다.
* **에셋 유형별 제작 분리 원칙**:
  * **인게임 핵심 에셋 (고화질 이미지 파일 - PNG / WebP)**:
    * 🖼️ **배경(Scene Background)**: 깊이감과 따스한 햇살이 느껴지는 16:9 비율의 수채화 숲/과수원/교실 배경.
    * 🐿️ **메인 캐릭터(Character)**: 풍부한 표정과 따뜻한 감성이 살아있는 그림책 일러스트.
    * 🍎 **상호작용 오브젝트(Interactive Items)**: 과일, 도토리, 낱말 카드, 악기 등 아이들이 직접 만지는 오브젝트는 촉감이 느껴지는 고품질 텍스처 이미지 적용.
  * **시스템 UI 에셋 (SVG 코드)**:
    * 상단 프레임, 뒤로가기 버튼, 음소거/전체화면 아이콘, 게이지 바 등은 가볍고 반응형에 최적화된 깔끔한 SVG 유지.

## 2. 플레이 구조 & 진행 표준 (Gameplay Flow)

### ⏱️ 플레이 세션: 1~2분 내외의 집중도 맞춤 설계
* 유아(만 3~5세)의 발달 단계와 집중 지속 시간을 고려하여 1회 플레이는 **1~2분 내외**로 완결됩니다.

### 📈 3단계 난이도 발전형 (3-Stage Progression)
* **1단계 (탐색·기초)**: 직관적으로 바로 이해하고 성공할 수 있는 가벼운 난이도 (예: 4~5개 수집, 단순 짝맞추기).
* **2단계 (응용·발전)**: 조금 더 관찰하거나 분류 규칙이 추가되는 난이도 (예: 색상/종류 복합 분류).
* **3단계 (도전·완성)**: 성취감을 줄 수 있는 단계로, 클리어 시 큰 만족감 제공.
* **보상 연출**:
  * 3단계 완주 시 ⭐⭐⭐(별점 3개)와 함께 캐릭터의 기쁜 반응 및 "참 잘했어요!" 축하 모달 노출.
  * 언제든 처음부터 다시 하거나 단계를 재도전할 수 있는 루프 제공.

## 3. 사운드 디자인 원칙 (Sound Design)

### 🌿 교실 친화적 소프트 터치 음향 (Classroom-Friendly Soft Tone)
* **사운드 방향성**:
  * 유치원, 어린이집 교실이나 가정에서 여러 아이가 함께 활동할 때 시끄럽거나 산만하지 않도록 **자극적인 아케이드 전자음은 철저히 배제**합니다.
  * 터치 시 부드럽게 '톡', '통' 울리는 나무/물방울 소리, 자연의 소리, 차분하고 맑은 음계 피드백을 지향합니다.
* **시스템 제어**:
  * 메인 호스트 화면의 상단 툴바 볼륨 버튼 및 인게임 내 음소거 버튼이 상호 즉각 연동되어야 합니다.

## 4. 파일 및 디렉토리 표준 (Architecture Standard)

### 📁 게임별 독립 모듈형 디렉토리 구조
모든 게임은 다른 게임이나 메인 페이지에 의존하지 않고 독립적으로 실행될 수 있어야 하며, 각 폴더 내에 모든 에셋을 완비합니다.

```
games/
├── GAME_CREATION_RULES.md          # 본 제작 표준 지침
├── registry.json                   # 전체 게임 목록 및 메타데이터 인덱스
├── shared/
│   └── game-bridge.js             # 호스트-게임 iframe 양방향 통신 브릿지
│
└── {game-id}/                     # 개별 게임 독립 폴더
    ├── GAME_BRIEF.md              # 게임 기획 요약 및 교육 목표 (누리과정 연계)
    ├── manifest.json              # 게임 메타 정보 (영역, 연령, 대표 이미지 경로)
    ├── index.html                 # 게임 단독 실행 가능한 HTML 엔트리
    ├── style.css                  # 게임 전용 스타일시트
    ├── src/
    │   └── game.js                # 게임 로직 스크립트
    └── assets/                    # 게임 전용 수채화 이미지 에셋
        ├── bg.png                 # 수채화 배경 일러스트 (16:9)
        ├── character.png          # 메인 캐릭터 일러스트
        └── items/                 # 게임별 상호작용 오브젝트 이미지들
```

### 🔌 브릿지 통신 규격 (`game-bridge.js`)
* 호스트(`section-pages.js`)와 게임 iframe은 `window.postMessage` 기반의 표준 규격을 준수합니다:
  * `HOST_RESTART`: 게임 처음부터 다시 시작
  * `HOST_SET_MUTED`: 호스트 볼륨 설정 동기화
  * `GAME_COMPLETE`: 스테이지 완료 통계 전송
  * `GAME_SCORE`: 실시간 점수 보고
  * `REQUEST_FULLSCREEN`: 전체화면 요청
  * `EXIT_GAME`: 게임 종료 및 목록 복귀
