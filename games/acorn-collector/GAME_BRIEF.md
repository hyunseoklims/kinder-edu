# 다람쥐의 도토리 모으기 (Acorn Collector)

## 1. 기본 정보
- 게임 ID: `acorn-collector`
- 상태: `ready` (데모 프로토타입 완성)
- 대상 연령: 만 3~5세
- 교육 영역: 자연탐구, 수·과학 (1:1 대응 수 세기)
- 한 판 시간: 약 3분
- 권장 방향: landscape (가로 모드 우선, 반응형 contain)
- 기준 캔버스: `1000 × 660px`

## 2. 한 문장 설명
가을 숲속 낙엽 사이에서 흩어진 도토리를 찾아 세며 다람쥐 바구니에 담는 수·자연탐구 놀이

## 3. 교육 목표
- 낙엽 속에 숨은 도토리를 탐색하며 집중력과 관찰력을 기른다.
- 도토리를 하나씩 바구니에 담으며 1부터 5까지 숫자를 자연스럽게 세어본다.
- 목표를 달성하며 긍정적인 성취감과 가을 계절감을 느낀다.

## 4. 핵심 플레이
1. 가을 숲속 배경에서 흩어져 있는 도토리 5개를 찾는다.
2. 도토리를 클릭/터치하면 숫자가 커지며 바구니로 통통 튀어 날아간다.
3. 5개를 모두 모으면 다람쥐가 기뻐하며 축하 팡파레와 피드백이 나타난다.
4. 다시 하기 버튼을 누르면 도토리가 새로운 위치에 숨겨져 반복 놀이가 가능하다.
