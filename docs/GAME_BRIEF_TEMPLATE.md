## 12. Launcher 통신

게임이 보내는 이벤트:

- `GAME_READY`
- `GAME_START`
- `GAME_PAUSE`
- `GAME_RESTART`
- `GAME_COMPLETE`
- `GAME_ERROR`
- `REQUEST_FULLSCREEN`
- `EXIT_GAME`

게임이 처리할 부모 명령:

- `HOST_PAUSE`
- `HOST_RESUME`
- `HOST_RESTART`
- `HOST_SET_MUTED`
- `HOST_EXIT`
